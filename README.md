# T-Business Empire HQ

A responsive business command-center dashboard for tracking ventures, cash flow, priorities, and team momentum.

## Run locally

Open `index.html` directly in a browser, or serve the directory with any static file server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Features

- Responsive desktop and mobile dashboard
- Venture portfolio overview
- Revenue, cash position, and focus metrics
- Interactive priority checklist
- Add-action modal
- Mobile sidebar navigation

## Customize

Update company and dashboard values in `index.html`, visual styles in `styles.css`, and interactions in `script.js`.
